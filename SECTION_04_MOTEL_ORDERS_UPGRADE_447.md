# Upgrade 447 — Latest Evidence Guard UI

Adds **Latest Evidence Check** to the staff Customer Identity Onboarding panel, connected to the read-only RPC from Upgrade 446. Shows latest evidence review, dispute status, provider verification gap, and explicit blocks for identity activation, customer consent and credit debit. Backend errors fail closed in the UI. No provider is connected and no identity/credit activation is permitted.

Flutter compilation and live Supabase testing are not available in this environment.
